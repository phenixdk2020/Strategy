# Danish Infantry 1864

Place the Mixamo-rigged base character here:

`Infantry_shape_T-Pose.fbx`

The editor importer in `Assets/Editor/Infantry1864HumanoidImporter.cs` automatically configures this FBX as:

- Animation Type: Humanoid
- Avatar Definition: Create From This Model
- Optimize Game Objects: Off (during validation)

After Unity imports the file, select the FBX and verify **Rig > Configure...** shows a valid green humanoid mapping.
