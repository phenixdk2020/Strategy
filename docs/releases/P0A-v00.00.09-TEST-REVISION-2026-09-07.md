# P0A v00.00.09 TEST revision — 2026-09-07

Denne revision er fortsat **v00.00.09 TACTICAL COMMAND TEST** og er ikke promoveret til `main`.

## UI safe-area

- Tactical command bar er fortsat to rækker, men er nu 58 px høj og ligger med 50 px horisontal margin og 42 px bundmargin.
- Battle time bar ligger centreret 20 px under øverste kant.
- Dato/klokkeslæt, Pause/Fortsæt og x0.5/x1/x2/x5/x20 er altid i samme topbar.
- F9 åbner/lukker KAMP-SETUP.
- Time-, command- og tuning-UI isoleres fra battlefield clicks.

## Move/facing controls

### Én valgt enhed

- Højreklik på terræn = destination.
- Hold højre museknap nede og træk = destinationen bliver ved første klik, mens drag-retningen bestemmer slut-facing.
- Ghost path viser marchen, og ghost footprint viser slutformation/facing.

### Flere valgte enheder

- Ctrl+venstreklik eller Shift+venstreklik tilføjer/fjerner enheder fra selection.
- Højre-drag på terræn tegner den linje regimenterne skal stå på.
- Drag-retningen bestemmer hvilken side af linjen de vender mod.

### Waypoints

- Alt+højreklik tilføjer et waypoint til den valgte formation/rute.
- Gentag Alt+højreklik for flere waypoints.
- Alt+højre-drag på sidste waypoint giver dette waypoint en eksplicit slut-facing.
- Ghost path viser de resterende route legs frem til sidste waypoint.

### Facing-trim

- Z = 15° venstre.
- X = 15° højre.
- Hvis en move-route findes, roteres slut-ghost/facing uden at annullere ruten.

## Combat tuning

KAMP-SETUP (`F9`) kan ændre følgende uden kodeændring:

- Grundtræf pr. skytte: 0.05–3.00 %.
- Close range multiplier: 0.50–3.00.
- Medium range multiplier: 0.20–2.00.
- Long range multiplier: 0.02–1.00.
- Andel mænd der skyder: 20–100 %.
- Start ammunition pr. mand: 10–120 runder.
- Tab pr. synligt casualty-body: 2–20.

Default TEST-værdier:

- Grundtræf: 1.40 %.
- Close: x1.75.
- Medium: x1.00.
- Long: x0.30.
- Firing fraction: 58 %.
- Start ammunition: 60 runder pr. mand.
- Casualty density: 1 synligt body pr. 8 tab.

Accuracy/faktorer virker straks. Start-ammunition bruges ved næste battle restart. Der er ingen automatisk ammunition-regeneration.

## Casualty visuals

Casualty bodies oprettes på regimentets aktuelle battlefield-position, når tabene passerer næste visual-threshold. De parent'es ikke til regimentet og bliver derfor liggende, hvor tabet indtraf. Dette gælder også når regimenter står stille og udveksler salver.
