# P0A v00.00.09 TEST — Officer AI

**Status:** TEST, ikke runtime-valideret.  
**Baseline:** v00.00.08 combat + design v00.02.08.  
**Branch:** `p0a-v00.00.09-officer-ai`

## Hvad der er implementeret

- Fælles officer decision core (`Assets/Scripts/OfficerAi.cs`) bruges af både preussiske regimenter og danske regimenter med `AI UNIT ON`.
- `A` slår AI UNIT ON/OFF på valgte danske regimenter. Preussiske regimenter er altid AI-styret.
- Missioner i MVP: `Hold` / `DefendArea` / `AdvanceAttack`.
- QA-officerprofiler (ikke historiske vurderinger):
  - 1. Regiment — Maj. Petersen (høj taktisk, lav aggression)
  - 5. Regiment — Kapt. Holm (høj initiative/aggression)
  - 8th Regiment — Maj. von Stein (høj taktisk, forsigtig)
  - 18th Regiment — Hptm. Krueger (lav taktisk, meget aggressiv)
- Difficulty `I`: Easy / Normal / Hard. Ændrer kun tænketid, målstøj og Hard-koordinering. Ingen ændring af accuracy, reload, range, morale, cohesion eller movement.
- UI viser AI ON/OFF, officer, current task og reason code. Console logger `[AI] ...`.
- Manuel override (højreklik / H) virker stadig. Ved AI ON bliver ordrer til officerens mission.

## Bevidst ude

Courier/order-delay, brigadehierarki, skirmishers, cover, ammunition, artilleri-fire-control, fog of war.
