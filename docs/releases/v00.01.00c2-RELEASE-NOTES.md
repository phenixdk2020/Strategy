# PROJECT 1864 — v00.01.00c2 TEST

## Soldier Visual Upgrade + Hover Info

### Formål

v00.01.00c2 er et isoleret presentation/UI-pass oven på den rene Company-first rebuild. Versionen ændrer ikke movement, navigation, combat eller AI.

### Implementeret

- Bevarer præcis 8 tactical Companies: 4 danske og 4 preussiske.
- Bevarer 1:1 manpower-visualisering: 759 danske + 812 preussiske = 1571 synlige soldater.
- Bevarer Stable UnitID, Company world pose og det eksisterende selection-system.
- Fjerner permanente world-space Company-labels.
- Tilføjer mouse-over infoboks med Regiment, Battalion, Company, nation, strength, formation, UnitID og selected state.
- Forbedrer soldier silhouette med smallere torso, separat coat skirt, capsule-ben, to arme, cross-belt og pack.
- Geværet tegnes nu som separat stock + metal barrel + bayonet, så våbnet er tydeligere ved close/medium zoom.
- Dansk og preussisk QA-uniformpalette er fortsat tydeligt adskilt.
- Renderer er fortsat presentation-only og skriver aldrig movement/combat/OOB-state.
- Ingen almindelig soldat får eget GameObject, MonoBehaviour, Collider, NavMeshAgent eller Animator.
- LOD: Full <= 250 m, Medium <= 500 m, Far <= 850 m.

### Ikke implementeret i denne version

- Regiment-/nationalfaner: bevidst udskudt efter seneste QA-feedback.
- Company movement/navigation: Gate D.
- Company combat/reload/ammo/casualties: Gate E.
- Officer AI og Brigade AI.
- Cavalry/dragoons og artillery runtime.

### Selection — uændret

- LMB: vælg ét dansk Company.
- Shift + LMB: add.
- Ctrl + LMB: toggle.
- LMB drag: box select.
- Esc: clear.
- RMB: movement er stadig deferred og udfører ingen movement.

### Acceptance

1. Unity 6000.6.0f1 compiler uden røde fejl.
2. Build marker viser `PROJECT 1864 | v00.01.00c2 TEST`.
3. Console viser `REBUILD-RENDER-00C2|Installed=True`.
4. Console viser `REBUILD-HOVER-00C2|Installed=True`.
5. 8 Companies og ca. 1571 soldater er synlige.
6. Permanente hvide labels over formationerne er væk.
7. Mouse-over infoboksen følger korrekt Company.
8. Selection fungerer identisk med v00.01.00c.
9. Soldier silhouette og rifle readability er tydeligt forbedret.
10. FPS/GC forbliver acceptabel.
11. RMB flytter stadig ingen units.

### Arkitekturregel

Denne version må ikke bruges til at introducere nye authority-/compatibility-lag. Company forbliver first-class tactical entity, og renderer/hover UI er rene read-only presentation-lag.
