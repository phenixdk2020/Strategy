WHY v10h EXISTS:
Unity QA screenshot on 12 September 2026 showed provider 9 stuck/visible at LOADING 18/30 with only the northern raster rows rendered, while the remaining screen showed the blue campaign background. v10e and v10g IMGUI also overlapped at the top/bottom of the Game view.

ROOT CAUSE:
- v10g raster loading was sequential.
- Raster provider roots were deactivated when another map was selected.
- Unity stops coroutines on inactive GameObjects.
- v10g kept loadStarted=True after that stop, so reselecting the provider could leave it permanently frozen at a partial tile count such as 18/30.
- Tiles were revealed individually while loading, producing a visible hard horizontal edge between loaded raster rows and the empty background.

v10h RASTER FIX:
- Up to 6 raster tiles load concurrently instead of one at a time.
- Aalborg/Limfjord tiles receive first priority in the queue.
- Successful materialized tiles are remembered across provider switches.
- On provider deactivation, the old load generation is invalidated and loading state becomes resumable.
- Reselecting a partially loaded raster provider resumes/retries instead of remaining stuck.
- Raster tile root remains hidden while the overview set is loading.
- The raster is revealed atomically only when the current overview set has completed.
- Failed source tiles receive a neutral missing-tile patch, never data from another provider.
- Existing seven-day local raster cache remains active.

v10h UI FIX:
- Runtime basemap header now reports v00.00.10h.
- Obsolete v10e build badge in the upper-left is masked by the v10h build badge.
- Campaign clock and speed controls remain visible and interactive.
- Provider toolbar reserves an opaque bottom UI region so old Natural Earth map-info text and city labels no longer paint through the basemap buttons.
- Loading providers show a centered LOADING status instead of exposing a half-built map.
- Provider source, requirements, attribution and Aalborg/Limfjord QA requirement remain visible in the upper-right information panel.
