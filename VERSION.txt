v00.00.09h2 - Attack frontage stability fix
- Screenshot QA showed one Danish regiment remaining far behind while the other three advanced into engagement.
- Root cause candidate identified in PrototypeAttackFrontagePlannerV2: secondary frontage slots were fully rescored every 0.25 seconds, allowing a unit to chase a moving/flipping slot while V3 simultaneously steered toward the latest destination.
- Frontage slots are now sticky once allocated.
- A slot is reconsidered only when it becomes blocked/conflicted, the target moves materially, or the regiment makes no meaningful progress for 3.5 seconds.
- No-progress recovery deliberately excludes the current slot from the next choice so the unit tries an alternate frontage instead of reissuing the same failed destination.
- Progress is measured against distance-to-slot with 0.65 m hysteresis so tiny movement/noise does not count as real progress.
- Attack target selection gains hysteresis: a new nearest enemy must be materially closer before frontage ownership switches, reducing target churn between nearly equal enemies.
- New telemetry prefix: AI-SPACING-V3. Replan reasons include InitialSlot, SlotConflict, SlotBlocked, TargetMoved and NoProgress; RecoveryCount increments on genuine no-progress recovery.
- Navigation V3 remains the sole steering owner. 09h2 does not modify V3, 09B tree pass-through, combat resolution, Officer AI decision timing or player movement controls.

v00.00.09h - RTS box selection
- Normal LMB click remains the existing single-unit selection behavior.
- LMB drag beyond 9 pixels shows a translucent marquee rectangle.
- On release, all non-routed Danish regiment centres inside the rectangle are selected.
- No modifier = replace selection.
- Shift + drag = add units inside the rectangle to the existing selection.
- Ctrl + drag = toggle units inside the rectangle against the selection state captured at mouse-down.
- Enemy/Prussian regiments cannot be selected by the player box selector.
- Box selection changes selection only and never issues movement or combat orders.
