- Former provider 9 World Imagery is the selected campaign basemap.
- Campaign3 no longer creates or exposes runtime roots/buttons for DEM, Cesium, ArcGIS Topographic, MapTiler, historical WMS, QGIS baked, procedural, OSM, diorama or HOI4 basemap candidates.
- M / [ / ] / Shift+F1...F11 provider switching is removed from the active campaign runtime.
- Old provider implementation files remain in the repository for history/rollback but are not instantiated by v10j.

WORLD IMAGERY RUNTIME:
- Source: Esri World Imagery XYZ service for the current development prototype.
- Camera-driven world streaming is retained from v10i.
- Dynamic Web-Mercator LOD uses z2 through z12.
- Maximum visible/requested tile budget remains 96 tiles.
- Up to 8 tile requests run concurrently.
- Tiles nearest the camera center are requested first.
- New generations load hidden and atomically replace the previous visible generation.
- Persistent zoom/x/y cache is retained.
- Runtime-created textures, materials and meshes are released when old generations are replaced.

WORLD CAMERA CONTROLS:
- Home = Denmark overview.
- PageUp = Europe overview.
- End = world overview.
- WASD / arrow keys = pan.
- Middle mouse drag = grab/pan.
- Mouse wheel = zoom.
- Start center remains 10.20 E / 56.10 N.
