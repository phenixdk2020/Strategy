v00.00.09k - Full-scale four-regiment pilot
- The old expanded eight-regiment 570-620 man QA layout is disabled before it can add the extra four units.
- Tactical pilot returns to the original four infantry regiments at realistic 1864-scale QA manpower:
  * 1. Regiment (DK): 1,620
  * 5. Regiment (DK): 1,587
  * 8th Regiment (PR): 2,460
  * 18th Regiment (PR): 2,440
- Total full-scale infantry manpower: 8,107.
- These are agreed QA scale values, not yet source-certified date-specific strengths for those exact named regiments.

v00.00.09k - Battalion/company OOB
- New PrototypeRegimentOOB09K attaches persistent structural OOB data to each regiment.
- Danish regiment = 2 battalions x 4 companies = 8 companies.
- Prussian regiment = 3 battalions x 4 companies = 12 companies; third battalion is labelled Füsilier-Bataillon.
- Approximately 25 men are reserved as regimental staff; remaining manpower is distributed across companies so the OOB sums to the regiment strength.
- Regiment remains the movement/combat/selection owner in 09k; battalion/company is the future officer allocation layer.

v00.00.09k - 1:1 infantry renderer
- New PrototypeFullScaleRenderer09K displays one visual infantryman per current manpower without creating one GameObject/MonoBehaviour/NavMeshAgent/collider per man.
- Uses instanced body/head/headgear/rifle meshes in <=1023 instance batches.
- Existing 09h/09i representative soldier renderers and 09j representative reload animator are disabled to prevent duplicate formations.
- 1:1 rifle pose still follows the actual outgoing-volley/reload window from Regiment.nextFireTime.
- Muzzle-loader and Dreyse receive different simplified reload rifle poses.
- Company/battalion slots create large formation blocks; Column uses an eight-file march column.
- Renderer writes no movement, combat, morale, cohesion, selection or Officer AI state.

v00.00.09k - Mounted regimental HQ
- Every infantry regiment gets a three-rider command group:
  1. commander,
  2. adjutant,
  3. orderly/staff rider.
- The three riders replace three visual staff manpower slots rather than being added on top of regiment strength.
- HQ is visual in 09k; later it becomes command origin for courier delay, officer casualties and command effectiveness.

v00.00.09k - Officer mission architecture
- New PrototypeOfficerObjective09K stores explicit high-level mission state: None, DefendArea, AttackCaptureArea.
- Stores objective centre, radius and requested reserve fraction.
- This is intentionally a scaffold only in 09k: it does not fake battalion/company reserve decisions before subunits can move independently.
- Intended command model: player gives an officer an objective; officer AI allocates subordinate battalions/companies between ENGAGED, SUPPORT and RESERVE and commits additional reserves as required.

v00.00.09k - Dragoons pilot
- Adds one QA dragoon squadron per side, 160 mounted riders each.
- Separate horse/rider/carbine visual identity; not an infantry reskin.
- Mounted movement, dismount, horse holders, remount, fatigue/casualties and dragoon combat are future functional gates.

v00.00.09k - Field artillery pilot
- Adds one QA field battery per side.
- Six guns + approximately 120 crew per battery.
- Gun carriage, wheels, barrel and crews are rendered separately.
- Limber/unlimber, horses, deployment, ammunition, LOS/fire arcs, counter-battery and capture/abandon remain future functional gates.

Performance direction
- 09k is the first architecture test for realistic 1:1 manpower rendering.
- Immediate scenario load: 8,107 infantry + 12 mounted HQ riders + 320 dragoons + 240 artillery crew + 12 guns.
- Future benchmark gates: 10k, 20k, 40k visible men, optional 60k stress test.
- Measure FPS, main-thread ms, GPU ms, memory and draw calls at close, medium and full-battlefield zoom.

Retained movement/combat baseline
- Navigation V3 remains steering authority.
- 09i1 Farmhouse/Barn continuation fix remains active.
- 09h4 manual AI-OFF route recovery remains active.
- Decorative trees/fence posts remain soft/pass-through; Farmhouse/Barn remain hard; river remains bridge-only.
- 09j combat reload cadence is unchanged; 09k only replaces its representative visual layer with 1:1 rendering.
- Fire policy, range cone, accuracy, casualties, morale/cohesion and Officer AI combat logic remain unchanged.

Known migration item
- Unity Input Manager deprecation warning is non-blocking. Input System migration remains a separate controls revision because LMB/RMB, box-select, F10 and keyboard shortcuts must move together.
