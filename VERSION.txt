v10g PURPOSE:
- Replaces the v10f concept of one Natural Earth mesh with eleven render styles.
- Creates eleven separate basemap provider roots named BASEMAP_01_* through BASEMAP_11_*.
- Only the selected basemap root is active.
- The old v10e Natural Earth renderers remain in the project as a rollback/geography scaffold but are hidden by v10g and are NOT used as a silent fallback.
- Shared campaign gameplay remains separate: city, zone and army coordinates retain WGS84 identity.
- Provider status is shown in Play mode. Missing API keys/assets are reported explicitly as KEY REQUIRED / ASSET MISSING.

TRUE 11 BASEMAP PROVIDERS:
1. DEM / DHM-GEODANMARK TARGET
   - Active pilot: Mapzen Terrain Tiles / AWS Terrarium elevation.
   - Builds its own 3D mesh per terrain tile.
   - Explicit hydrology mask cuts Limfjorden and selected major fjords from land geometry.
   - Official Danish DHM/GeoDanmark remains the target source for the production Denmark provider and requires Datafordeler integration/credentials.

2. CESIUM WORLD TERRAIN
   - Cesium for Unity 1.25.1.
   - Cesium World Terrain ion asset 1.
   - Bing Maps Aerial ion raster overlay asset 2.
   - Requires CESIUM_ION_TOKEN, persistent token file, or Cesium project default token.

3. ARCGIS TOPOGRAPHIC
   - Independent Esri World_Topo_Map raster XYZ provider.
   - Denmark overview loaded at z8 into separate WGS84-projected tile geometry.

4. MAPTILER 3D TERRAIN
   - Cesium FromUrl provider using MapTiler terrain-quantized-mesh-v2.
   - MapTiler streets-v4 raster overlay through Cesium URL-template overlay.
   - Requires MAPTILER_API_KEY or persistent key file.

5. HISTORICAL DANISH MAP
   - Datafordeler Høje målebordsblade WMS.
   - Historical 1:20,000 sheets from the 1842-1899 survey/issue period.
   - Runtime WGS84 -> ETRS89/UTM32 conversion for WMS BBOX requests.
   - Requires DATAFORDELER_API_KEY or persistent key file.
   - No modern fallback is shown if credentials are absent.

6. QGIS / BLENDER BAKED
   - Independent local baked-map adapter.
   - Reads StreamingAssets/PROJECT1864/Basemaps/QGIS/qgis-denmark.png.
   - Reads WGS84 extent from qgis-denmark.bounds (minLon,minLat,maxLon,maxLat).
   - Shows ASSET MISSING instead of substituting another map.

7. PROCEDURAL DENMARK
   - Own runtime terrain/landcover mesh.
   - Independent generated materials and relief.
   - Uses the project geography mask only as a coastline scaffold and applies v10g hydrology mask including Limfjorden.

8. OPENSTREETMAP
   - Independent OpenStreetMap Standard raster XYZ provider at z8.
   - Visible attribution: © OpenStreetMap contributors.
   - Persistent tile cache with minimum seven-day freshness window.
   - Intended only for interactive comparison, not bulk/offline download.

9. REALISTIC IMAGERY
   - Independent Esri World Imagery raster XYZ provider at z8.
   - Modern imagery is comparison/reference only and is never presented as 1851 truth.

10. DIORAMA / MODEL TERRAIN
   - Own generated 3D terrain mesh.
   - Own physical landscape dressing and miniature city geometry.
   - Hydrology mask includes Limfjorden and selected major fjords.

11. HOI4 / PROVINCE MAP
   - Own strategic province-cell geometry generated from campaign-zone centres.
   - Own province materials and adjacency/border layer.
   - Land/water mask includes Limfjorden.
   - Province cells are simulation scaffolding, not historical administrative borders.

CONTROLS:

- [ = previous basemap.
- Shift+F1 ... Shift+F11 = direct basemap selection.
- Cesium/MapTiler globe mode: WASD/arrows pan, mouse wheel zoom, middle mouse drag pan, Home resets Denmark view.
