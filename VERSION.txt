v00.01.00c4 - Animated Drill + Visual Soldier Scale
- Builds directly on v00.01.00c3.
- Active OOB remains exactly eight independent Companies: four Danish and four Prussian.
- Actual tactical manpower remains Denmark 759 + Prussia 812 = 1571 men.
- Stable UnitID/OOB and clean Company-first ownership remain unchanged.
- F no longer teleports between Line/Column. Selected Danish Companies reform over 2.2 seconds.
- Z/X no longer snap facing. Selected Danish Companies rotate +/-15 degrees over 0.75 seconds in place.
- Company world position is preserved throughout drill transitions; this is not Gate D movement.
- Renderer interpolates each visible soldier between its old and new formation slot during reforming.
- Selection footprint, hit box and outline interpolate with the formation footprint.
- F10 opens visual settings.
- Soldier visual ratios available: 1:1, 1:2, 1:3, 1:4, 1:5, 1:10, 1:20.
- Ratio is VISUAL ONLY. Example: a 190-man Company at 1:2 renders 95 representative soldiers but retains PresentStrength=190.
- Reduced representatives are sampled across the entire canonical full-strength formation, so 1:2 does not halve formation frontage/depth.
- Future movement, combat, ammo, casualties, morale and OOB calculations must always use actual strength/state, never representative count.
- c4 renderer improves the low-poly soldier again: tapered torso/coat, separate legs/boots, arms/hands, belts, pack, cartridge box, musket stock, metal barrel and bayonet.
- Permanent world labels remain removed.
- H now has explicit ON/OFF feedback and controls the c4 mouse-over info panel.
- Hover panel also shows current visual ratio, representative count and drill transition state.
- V toggles Debug/Clean presentation with explicit feedback.
- Legacy c2/c3 presentation scripts are suppressed only as superseded presentation components; tactical ownership is unchanged.
- No standards/flags in this revision.
- RMB movement remains OFF and deferred to Gate D.
- Navigation, combat, Officer AI, Brigade AI, artillery and cavalry remain inactive.

Controls
- LMB: select Danish Company.
- Shift+LMB: add to selection.
- Ctrl+LMB: toggle selection.
- LMB drag: box selection.
- Esc: clear selection.
- F: animated Line <-> Column reform (2.2 s).
- Z/X: animated facing left/right 15 degrees (0.75 s).
- F10: open/close visual settings.
- H: hover info ON/OFF.
- V: Debug/Clean view.
- RMB: still intentionally ignored until Gate D.

Visual scale semantics
- 1:1 = one rendered representative per actual soldier.
- 1:2 = approximately half the rendered soldier figures.
- 1:3 / 1:4 / 1:5 / 1:10 / 1:20 = progressively fewer presentation figures.
- Tactical manpower never changes when this setting changes.
- Formation dimensions remain based on actual manpower, not displayed representatives.
