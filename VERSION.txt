3D TERRAIN SOURCE / CONTRACT:
- Elevation pilot source: Mapzen/AWS Terrain Tiles in Terrarium encoding.
- Terrain elevation is requested only for active/pending World Imagery tile identities.
- Minimum terrain LOD is z5; low-detail world overview can remain flat/top-down.
- Elevation cache: <persistentDataPath>/PROJECT1864/TerrainCache/terrarium/<z>/<x>/<y>.png
- If an elevation tile fails, the corresponding imagery remains visible as flat terrain.
- Terrarium is a development/global height pilot and is NOT claimed to be official Danish DHM.
- Production Denmark high-detail terrain remains targeted at Danish DHM/GeoDanmark data.

MESH / LOD:
- Imagery tile materials remain the visible surface.
- Each elevation-enabled imagery tile is subdivided into a grid.
- Grid density increases with map LOD:
  z5: 6x6 cells
  z6-z7: 10x10
  z8-z9: 16x16
  z10: 20x20
  z11-z12: 24x24
- Terrain uses strategic vertical exaggeration x18 so Danish relief is readable at campaign scale.
- No MeshCollider is added to terrain; army/zone selection remains owned by existing gameplay colliders.

3D CAMERA:
- 3D terrain is enabled by default.
- T = toggle 2D / 3D.
- Q / E = rotate the strategic 3D camera around the current map centre.
- Home = Denmark.
- PageUp = Europe.
- End = world overview.
- WASD / arrow keys = pan.
- Middle mouse drag = pan.
- Mouse wheel = zoom.
- Camera becomes progressively more top-down at larger strategic scales.
- At world overview scale the camera auto-flattens rather than forcing a horizon-heavy 3D view.

GAMEPLAY MARKER HEIGHTS:
- ZONE_ markers are lifted to sampled terrain height + their existing visual offset.
- CITY_ markers are lifted to sampled terrain height + their existing visual offset.
- ARMY_ markers are lifted after GrandCampaignBootstrap movement updates so armies remain above terrain.
- If no active terrain sample exists, markers return to their previous flat-map Y baseline.
