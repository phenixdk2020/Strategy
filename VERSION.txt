v00.00.09f3 - Visible formation transition
- Line/Column changes no longer need to read as an instantaneous formation teleport.
- PrototypeFormationMotion09F3 tracks representative Soldier_* transforms and moves them physically toward their new Line/Column slots with a bounded movement speed.
- Formation changes caused by manual F/C, long-march Column policy and automatic deployment back to Line use the same visual transition.
- Existing Regiment formation/combat state remains authoritative; the 09f3 layer changes presentation timing only.
- Telemetry prefix: FORMATION-MOTION-09F3.

v00.00.09f3 - Visible left/right facing change
- Existing Z/X and bottom-bar 15-degree facing commands are retained.
- Instant root-transform facing jumps are intercepted while the regiment is stationary.
- Regiment facing now turns progressively at approximately 24 degrees/second.
- Route-completion facing changes therefore also become visible physical turns instead of a one-frame snap.
- Movement steering remains owned by existing movement/AI code and is not artificially slowed by this facing layer.
- Telemetry prefix: FORMATION-TURN-09F3.

v00.00.09f3 - Bridge-only river rule
- The successful 09f2 pass-through result for scenery is retained: Trees, FencePost, Farmhouse and Barn do not block regiment movement.
- River/water is no longer pass-through.
- PrototypeRiverBridgeOnly09F3 is the sole tactical route constraint in this QA build.
- A movement segment that would touch open water is redirected to the fixed bridge at z=22.
- The regiment approaches the bridge on its own bank, crosses to the opposite bridge approach, then resumes the original final goal.
- A hard safety guard restores the last legal position if any other system places the regiment centre in open water outside the bridge zone.
- All legacy obstacle/pathfinding writers remain runtime-disabled so the previously reproduced scenery stalls cannot return through V1/V3/V4/09A/recovery layers.
- Telemetry prefix: RIVER-09F3.
