Previous accepted/retained layers

- v00.00.09g scenic battlefield, larger camera range and enhanced regimental standards are retained.
- Scenic outer battlefield remains presentation-only; central 360x240 tactical core remains authoritative movement/click surface until navigation bounds are widened separately.

v00.00.09h - Soldier Visual Pass 1
- PrototypeSoldierVisualPass09H upgrades every existing representative infantry figure without replacing Regiment gameplay state.
- Existing capsule body/rifle/headgear are refined and supplemented with visible head, separate trousers/legs, belt/straps, pack/equipment and bayonet silhouette.
- Danish and Prussian infantry receive visibly different default colour profiles and headgear silhouettes.
- Prussian representative soldiers receive a prototype spike silhouette; Danish soldiers receive a distinct brim/detail silhouette.
- Representative soldier 1 receives officer sash/sword details; representative soldier 2 receives standard-bearer sash details.
- Soldier visual pass never writes Regiment destination, formation, strength, morale, cohesion, fire policy or Officer AI state.

v00.00.09h - Per-regiment uniform profiles
- PrototypeUniformProfile09H stores Coat, Trousers, Headgear, Trim, Straps, Equipment, Skin, FlagPrimary, FlagSecondary and Ribbon colours.
- Faction defaults exist for Denmark and Prussia.
- Regiment defaults exist for the current eight-unit QA OOB so units can be visually distinguished while preserving faction identity.
- Uniform colours are presentation-only and never alter combat or movement statistics.

v00.00.09h - Uniform Designer
- F10 opens/closes the in-game uniform designer.
- Exactly one regiment must be selected for editing.
- Uniform/fane parts can be selected and RGB values changed with live preview.
- GEM stores the current regiment profile in local PlayerPrefs.
- INDLÆS restores a saved profile.
- REGIMENT STANDARD restores that regiment's QA default.
- FACTION STANDARD restores the faction default.
- Flag primary/secondary and ribbon colours update the existing 09g regimental standard.
- UI clicks inside the Uniform Designer are protected from battlefield selection/order input.

v00.00.09h - RTS box selection
- Normal LMB click remains the existing single-unit selection behavior.
- LMB drag beyond 9 pixels shows a translucent marquee rectangle.
- On release, all non-routed Danish regiment centres inside the rectangle are selected.
- No modifier = replace selection.
- Shift + drag = add units inside the rectangle to the existing selection.
- Ctrl + drag = toggle units inside the rectangle against the selection state captured at mouse-down.
- Enemy/Prussian regiments cannot be selected by the player box selector.
- Box selection changes selection only and never issues movement or combat orders.

v00.00.09h - Video QA fixes from optagelse 1(2).mp4
- 09g recording confirmed units reach engagement; the old multi-regiment tree-stall is not reproduced in this recording, so V3 movement code is deliberately unchanged in 09h.

- Ramte N feedback is now compact text-only rather than a large black battlefield box.

Regimental standards
- 09g enhanced centre standard with pole, finial, fold, cords and ribbon remains active.
- 09h uniform profiles can recolour flag primary/secondary fields and regiment ribbon at runtime.
- Final historical regimental colours still require source validation; current designs remain QA placeholders.

Future tactical unit gate
- Dragoons/cavalry and field artillery remain the next major non-infantry tactical unit types after visual/stability acceptance.
- Dragon design baseline: mounted/dismounted states, horse fatigue/casualties, horse-holder state and timed remount; mounted mobility and dismounted sustained fire cannot be active simultaneously.
- Artillery design baseline: battery/piece count, gun type, crew, horses/limber, deploy/unlimber, ammunition mix, LOS/fire arcs, counter-battery and capture/abandon states; artillery is not an infantry reskin.

Combat/navigation retained
- Fire geometry remains a directional 120-degree forward fire fan.
- Range fan remains selected-unit ghost overlay from 09f.
- Fire policy remains HOLD / CLOSE / MEDIUM / LONG.
- Reload, ammunition, casualty visuals, melee and Officer AI logic are unchanged by 09h visual/control work.
- Player right-click movement/facing, Alt+RMB waypoints, F/C formation, Z/X facing and route ghosts are retained.
- Simulation controls remain PAUSE / x0.5 / x1 / x2 / x5 / x20.
