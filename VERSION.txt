v00.00.09f1 - RTS box selection
- LMB drag beyond 9 pixels shows a translucent marquee rectangle.
- Normal drag replaces selection; Shift adds; Ctrl toggles.
- Only non-routed Danish regiment centres are selected by the marquee.
- Ordinary single-click selection remains owned by PlayerCommander.
- Box selection changes selection only and never writes movement or combat orders.
- Telemetry prefix: SELECT-09F1.

v00.00.09f1 - March column and deployment
- Long manual PlayerCommander routes use Column while more than 14 m from the active waypoint.
- Manual regiments deploy back to the route final formation when within 14 m of the active waypoint OR when the nearest enemy is within EffectiveRange + 12 m.
- AI-controlled regiments use Column during longer MoveToPoint/Attack approaches and deploy to Line near destination/contact.
- Navigation V3 may still temporarily force Column for hard obstacle/bridge passage.
- Telemetry prefixes: MANUAL-FORMATION-09F1 and FORMATION-09F1-AI.

v00.00.09f1 - Manual movement stall recovery
- Active manual PlayerCommander routes with Officer AI OFF are monitored for useful movement progress.
- If a regiment moves less than 0.45 m for 3.5 seconds while still more than 5 m from its waypoint, a controlled bypass waypoint is inserted into the existing route.
- Bypass candidates use Navigation V3 Column validity/path penalty and reject unintended river crossings.
- Recovery is limited to four inserted bypass waypoints per active route with a 4-second cooldown to reduce oscillation.
- Navigation V3 remains the local steering owner; the recovery layer only modifies the higher-level route when a real stall is detected.
- Telemetry prefix: MANUAL-ROUTE-09F1.

v00.00.09f1 - Soft visual obstacles
- Decorative individual Trees remain pass-through.
- Individual FencePost objects are now also pass-through instead of forming a chain of hard circular obstacles.
- Farmhouse and Barn remain hard tactical obstacles.
- River/water remains bridge-only.
- Telemetry prefix: NAV-SOFT-09F1.

Retained v00.00.09f baseline
- Scenario: Danish test regiments are defenders; Prussian test regiments are attackers.
- TEST contains four Danish and four Prussian infantry regiments arranged in four starting lanes per side.
- Regimental standards remain visual identity only and follow regiment position/facing.
- Attack frontage deconfliction and obstacle-aware secondary frontage slots remain retained.
- Movement V3 remains the single authoritative steering layer; Navigation V4 and 09A stay runtime-disabled.
- Persistent obstacle detours preserve the original player/AI destination until the active obstacle is cleared.
- LINE formations narrow to COLUMN for hard building/bridge passage and restore after the passage clears.
- If a regiment centre is inside blocked tactical space, V3 emergency recovery moves it to the nearest legal Column-clearance position without discarding the original movement intent.
- The stream remains non-traversable terrain except through the fixed bridge zone.
- Battlefield tactical core remains 360x240.
- Fire geometry remains a directional 120-degree forward fire fan; no 360-degree firing ring.
- Range bands remain Close <= 50% EffectiveRange; Medium <= EffectiveRange; Long <= MaximumRange.
- v00.00.09f range-fan fix remains retained: material alpha is 1.0 and translucency is applied through LineRenderer vertex colour, preventing the nearly invisible 09e double-alpha cone.
- Fire policy remains HOLD / CLOSE / MEDIUM / LONG.
- Combat tuning menu remains F9/KAMP F9.
- Reload uses weapon profile base reload plus bounded regiment Experience modifier.
- Ammunition model remains rounds-per-man with no automatic regeneration.
- OfficerProfile + OfficerAIController remain attached to prototype regiments.
- I toggles AI UNIT ON/OFF for selected Danish regiments.
- Officer doctrine remains DEFENSIVE / BALANCED / OFFENSIVE.
- Persistent VALGT/VALGT xN battlefield panel remains hidden; bottom command bar remains the main command surface.
- UI clicks inside time/combat/command controls do not issue battlefield orders.
- Ctrl/Shift single-click multi-selection remains retained in addition to the new box selection.
- F/C manually select Line/Column; Z/X rotate facing.
- RMB destination + drag facing, multi-unit centred frontage, Alt+RMB waypoints and route ghosts remain retained.
- Casualty visuals, melee, smoke, morale/cohesion and current combat resolver remain unchanged by 09f1.
- Enemy officers remain Offensive with Medium fire policy under the existing 09f baseline.
- Difficulty F6/F7/F8 affects AI reaction/decision noise only, not combat stats.
- Pause and x0.5/x1/x2/x5/x20 simulation-speed semantics remain retained.

Known warnings
- Unity 6.6 may still report CS0618 warnings for legacy FindObjectsByType<T>(FindObjectsSortMode) calls in older navigation helper files.
- These are deprecation warnings, not compile errors, and are not the cause of the movement stalls addressed by 09f1.
- Input Manager deprecation warning is also non-blocking; Input System migration remains a separate controls revision.
