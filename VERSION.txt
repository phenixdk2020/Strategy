v00.00.09f4 - Living men are 1:1 by default
- Combat strength has always represented actual men; v09f4 now makes the default battlefield graphics match that number as well.
- PrototypeBattleVisuals09F4 hides the old fixed 1:10 Soldier_* representative meshes and draws one detailed instanced soldier for each living man when display scale is 1:1.
- F9 allows graphics-only display ratios 1:1, 1:2, 1:5 and 1:10. Changing the visual ratio never changes simulation strength, hit calculations, morale or casualties.
- 1. Regiment therefore displays CurrentStrength individual soldier figures at 1:1 instead of ceil(CurrentStrength/10).
- Formation slots are sampled consistently at reduced display ratios so changing performance scale does not change the regiment's intended footprint.
- Telemetry prefix: VISUAL-09F4.

v00.00.09f4 - Detailed Danish infantry graphics
- Danish battlefield figures receive a much richer 1850s/1860s prototype silhouette based on the supplied reference image.
- Visual components include dark navy tunic, light blue trousers, red collar/cuff/trim, white crossed leather belts, black shako, pompom/cockade detail, backpack, cartridge pouch, musket and bayonet.
- The model is built from shared instanced primitive meshes so hundreds of 1:1 figures do not require thousands of independent GameObjects.
- Prussian figures receive a corresponding dark-uniform prototype palette so both sides remain readable.
- This is an in-engine prototype visual pass, not the final rigged/animated production character asset.

v00.00.09f4 - Fallen men are 1:1 by default
- PrototypeCasualtyVisualManager's old capped/ratio body renderer is runtime-disabled by the new visual layer.
- Every actual strength loss creates an actual persistent fallen record at the regiment's battlefield position at the time of loss.
- At F9 fallen scale 1:1, one loss produces one visible fallen soldier.
- F9 can reduce fallen rendering to 1:2, 1:5 or 1:10 for performance while keeping the full underlying casualty record.
- Fallen positions remain behind when the surviving regiment moves.
- Telemetry prefix: CASUALTY-09F4.

v00.00.09f4 - F9 visual controls
- The existing KAMP F9 tuning panel gains a connected VISNING / TAKTISKE ORDRER section.
- Vis soldater cycles 1:1 -> 1:2 -> 1:5 -> 1:10.
- Vis faldne cycles independently through the same ratios.
- VISNING = 1:1 restores both to the requested default.
- Selected-unit feedback shows actual living men versus rendered living models and actual losses versus rendered fallen models.
- Pointer isolation prevents clicks on the F9 extension from issuing battlefield orders.
- Telemetry prefix: UI-09F4.

v00.00.09f4 - Tactical orders
- New explicit order modes are available from F9: FORSVAR HER, ANGRIB and EROBR HER.
- FORSVAR HER: select unit(s), choose the order, then left-click terrain. Units march to the point, use Column for the longer approach, redeploy to Line near arrival, then enter Defensive Officer AI around the ordered position.
- ANGRIB: select unit(s), choose the order, then left-click an enemy regiment. Selected units receive an explicit Offensive attack mission against that target.
- EROBR HER: select unit(s), choose the order, then left-click terrain. Units march to the point, deploy and hold/defend the captured position.
- Pending order mode is displayed at the top of the screen and ESC cancels it.
- Existing v09f3 bridge-only river authority remains later in the frame and may temporarily redirect the movement steering through the fixed bridge without losing the original Defend/Capture objective.
- Telemetry prefix: ORDER-09F4.

v00.00.09f4 - Danish national flag and regimental standard
- Older PrototypeNationalFlags09F2 and PrototypeRegimentalStandards runtime renderers are suppressed before they create duplicate placeholder flags.
- Danish national flag is a clearly readable Dannebrog with white cross geometry on both front and rear faces; camera direction can no longer make it appear as a plain red flag.
- Danish regimental standard uses a game-runtime derivative of the supplied SJLR.jpg reference on both faces, with dark-blue backing and gold finial.
- Packages/manifest.json now includes the Unity ImageConversion module used to load the embedded reference texture.
- Prussian units retain distinct black/white national and regimental identifiers.
- Telemetry prefix: FLAG-09F4.
