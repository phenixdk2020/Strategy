v00.00.09f13 - Destination facing indicator
- Added PrototypeDestinationFacing09F13.
- Active destination footprint now receives a small yellow chevron at its front edge.
- Chevron follows the route FinalFacing rather than merely the current regiment rotation.
- Purpose is to make the final facing readable before the company reaches/stops at the destination.

v00.00.09f13 - Volley telemetry for B-271 hit-rate calibration
- Added PrototypeVolleyTelemetryAudio09F13.
- Every detected volley now writes a compact VOLLEY-QA-09F13 Console line containing shooter, target, actual distance in metres, CLOSE/MEDIUM/LONG band, firing men, base-hit percentage, range factor, current quality factor, expected hits, resolved hits and target strength remaining.
- This is intended to collect repeated samples before changing Close-range lethality.
- Current F9 defaults remain BaseHit=1.40%, Close=x1.75, Medium=x1.00, Long=x0.30 and firing fraction=58%.

v00.00.09f13 - First-pass musket audio
- A lightweight procedural 3D black-powder volley sound is generated at runtime, so no external audio asset is required for this QA pass.
- Sound originates from the firing regiment and uses 3D distance attenuation plus slight pitch variation.
- This is a placeholder/prototype sound; a historically better recorded/curated musket library can replace it later without changing combat logic.

v00.00.09f13 - Fallen display control repaired
- F9 'Tab pr. synligt lig' now supports 1 instead of having a hard minimum of 2.
- The combat-tuning control is synchronized with PrototypeBattleVisuals09F4.CasualtyDisplayRatio, which is the ratio consumed by the active 09f7 renderer.
- The old duplicate/legacy casualty-manager ratio is no longer allowed to disagree with the active renderer.
- STANDARD now returns fallen display to 1:1.

v00.00.09f13 - Walking animation status
- Existing 09f7 renderer already has procedural WALK / Forced March / routed RUN states.
- WALK currently includes leg/boot swing, arm motion, carried-rifle pose and per-soldier vertical bob.
- It remains a first-pass procedural primitive animation rather than a skeletal/Mecanim animation; no new animation system is introduced in 09f13.

v00.00.09f12 retained - Route/pathfinding authority
